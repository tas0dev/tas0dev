## About me

I'm a systems programmer primarily working on operating systems and low-level software.

My main project is [mochiOS](https://github.com/tas0dev/mochiOS), an operating system built from scratch with a focus on security, reliability, and making computers personal again.

I also work on:

- OS and kernel development
- UEFI and boot systems
- CPU architecture and RISC-V
- Programming languages and toolchains
- Browsers and web engines
- Security research

I primarily use Rust and C.

I like building things from the lowest layers of the system upward.
